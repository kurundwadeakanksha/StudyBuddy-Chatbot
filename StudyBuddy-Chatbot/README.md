#  StudyBuddy Chatbot

## 1. Project Overview

StudyBuddy is a simple rule-based chatbot developed using Python.

The chatbot provides basic study-related assistance to students. It can respond to questions related to studying, Python, exams, motivation, breaks, greetings, and exiting the conversation.

This project was developed as part of the AI-Augmented Workflow self-learning task using GitHub Copilot as an AI-assisted coding tool.



## 2. Objectives

The main objectives of this project are:

- To develop a simple chatbot using Python.
- To learn how to use GitHub Copilot for AI-assisted coding.
- To understand and review AI-generated code.
- To modify and improve AI-generated code.
- To test the chatbot with different inputs.
- To maintain an AI Contribution Log.
- To use Git and GitHub for version control.



## 3. Technologies Used

- Python
- Git

- Visual Studio Code



## 4. Features

StudyBuddy can:

- Respond to greetings such as "hi", "hello", and "hey".
- Provide basic study suggestions.
- Provide basic Python learning advice.
- Give exam preparation advice.
- Provide motivational messages.
- Suggest taking breaks while studying.
- Handle unknown questions with a fallback response.
- Exit when the user enters "bye" .
- Handle empty user input.



## 5. How the Chatbot Works

The chatbot follows a simple rule-based approach.

User enters a message
        ↓
Convert message to lowercase
        ↓
Remove extra spaces
        ↓
Check the message
        ↓
Match it with predefined conditions
        ↓
Generate appropriate response
        ↓
Display response to user
